# webrtc-video-chat



A real-time peer-to-peer video chat application built with modern web technologies.



Tech Stack : 


**Frontend :**

* Vite
* React  19.2
* Typescript
* SignalR Client



**Backend :** 

* .Net 10.0.0
* SignalR
* Entity Framework Core
* SQL Server



**Real Time Communication :** 

* WebRTC  for peer to peer communication.
* SignalR for signaling 





\## Project Structure

```

webrtc-video-chat/

├── backend/

│   └── VideoChat.Api/          # .NET Web API

└── frontend/

&nbsp;   └── video-chat-ui/          # React + TypeScript

```
